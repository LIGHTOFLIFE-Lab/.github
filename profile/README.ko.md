## 01 / 회사와 방향 · Company & Purpose

**LIGHT OF LIFE는 Creative Venture Studio입니다.** 사람이 시작하고, 창작하고, 앞으로 나아가는 과정에서 만나는 장벽을 발견하고 기술·공간·경험으로 줄여갑니다.

| 구분 | 지향점 |
|:---|:---|
| **Mission** | 불편함을 없애고, 가능성을 비춘다. Remove barriers. Reveal possibilities. |
| **Vision** | 사람이 자신의 가능성을 발견하고, 더 큰 꿈을 꿀 수 있는 환경을 만든다. |

세 개의 독립적인 사업이 이 방향을 공유합니다. 각 사업은 서로 다른 고객과 사업모델을 갖습니다.

## 03 / 연구개발 · Research & Engineering

네 영역에서 제품의 문제를 실제로 작동하는 구현과 연결합니다.

| 영역 | 다루는 문제 |
|:---|:---|
| **Human–AI interaction** | 의도 구체화, 실행 가능한 지침 생성, AI 응답과 실제 실행의 연결 |
| **Evidence & information** | 정보의 맥락, 출처 추적, 검토할 수 있는 리서치 결과 |
| **Audio & creative technology** | 브라우저 오디오 처리, ML 연동, 라이브 현장의 행동 가이드 |
| **Workflow infrastructure** | MCP 연동, 동기화, 배포, 되돌릴 수 있는 변경 |

### 도구와 실험 · Tools & Experiments

공개 저장소를 선별해 소개합니다. 프로토타입과 실험은 위의 제품 포트폴리오와 별도로 정리합니다.

| 프로젝트 | 기술적 초점 |
|:---|:---|
| **[DevLink-MCP](https://github.com/LIGHTOFLIFE-Lab/DevLink-MCP)** | 서버 설정, MCP 연결, 파일 동기화·배포·롤백 |
| **[Markup TXT Studio](https://github.com/LIGHTOFLIFE-Lab/Markup-TXT-Studio)** | `ai.txt`·`llms.txt` 생성과 구조화 데이터 마크업 검색 |
| **[GEO-TESTER](https://github.com/LIGHTOFLIFE-Lab/GEO-TESTER)** · [GEO-DEMO](https://github.com/LIGHTOFLIFE-Lab/GEO-DEMO) | AI 검색을 위한 웹사이트 진단·탐색 실험 |
| **[SeeWe](https://github.com/Kimajun0919/SeeWe)** | 서울시 혼잡도 추정과 교통 정보를 보여주는 지도 기반 MVP |
| **[Yield Balance](https://github.com/Kimajun0919/Money-Balance)** | 개인 자산 관리·리밸런싱 프로토타입 |
| **[하늘의 걸음](https://github.com/LIGHTOFLIFE-Lab/Bibleverses-Card-Template)** | 성경 구절 추천과 공유할 수 있는 말씀 카드 이미지 |
